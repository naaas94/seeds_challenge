# Changelog

## seeds-match-api — 2026-05-28

- T1 (Project scaffold): Added empty Python package markers under `app/`, `app/agent/`, and `app/memory/`, plus `requirements.txt`, `.env.example`, and `tests/__init__.py`. Establishes the module path structure and dependency list for downstream subtasks. + added tests/test_scaffold.py
- T2 (Config, schemas, prompts): Added `app/config.py` (Pydantic `Settings` with required `openai_api_key`), `app/schemas.py` (chat/history/error models), and `app/agent/prompts.py` (`SYSTEM_PROMPT`). Anchors shared API types and startup validation for downstream agent and route work. + added tests/test_config.py, tests/test_schemas.py, tests/test_prompts.py. Adversarial gap deferred: invalid `model_name` env value is not validated until LLM init in later subtasks.
- T3 (Conversation store): Implemented `app/memory/store.py` with async `get`/`append`/`exists`, `asyncio.Lock`, and list-copy return discipline for in-process per-conversation memory. Enables T5/T6 to persist LangChain messages without cross-worker persistence. + added tests/test_store.py
- T7 (Docker configuration): Added `Dockerfile` (single-worker uvicorn CMD, curl for healthcheck) and `docker-compose.yml` (`api` service, `.env` loading, `/docs` healthcheck). Single-worker CMD preserves in-process `ConversationStore` semantics. Test coverage deferred per plan: Docker correctness is validated by `docker compose up --build` in Phase 3 (no unit-test slice for compose files).
- T4 (Yahoo Finance tool module): Implemented `app/agent/tools.py` with `@tool` `get_stock_info`, module-level singletons, and `init_singletons` / accessor functions; errors return strings and never raise. Enables the agent loop to dispatch Yahoo Finance lookups via a stable tool map key. + added tests/test_tools.py
- T5 (Explicit ReAct agent loop): Implemented `app/agent/loop.py` with `agent_loop`, `MAX_ITERATIONS = 10`, `not response.tool_calls` termination, system prompt prepended at invoke time only, and tool error handling as ToolMessage content. Primary evaluation artifact for loop mechanics (no AgentExecutor). See `.dev/decision-logs/T5-agent-loop.md`. + added tests/test_loop.py. Adversarial gap deferred: `AIMessage.content` as non-str list coercion is covered by implementation but not by a dedicated falsifier test.
- T6 (FastAPI application): Implemented `app/main.py` with lifespan startup (`init_singletons`, API key check), explicit `ROLE_MAP`, `serialize_content` for list content blocks, `POST /chat`, and `GET /chat/{conversation_id}` with 404 for unknown IDs. Wires the agent loop and in-process store into the HTTP surface required by the challenge. See `.dev/decision-logs/T6-main.md`. + added tests/test_main.py. Adversarial gap deferred: lifespan `RuntimeError` when `OPENAI_API_KEY` is empty string is not falsified (pydantic import path covers missing key; T8 may cover startup).
- T8 (Integration test suite): Added `tests/conftest.py` (fresh `ConversationStore` + mocked `ChatOpenAI` per test) and `tests/test_app.py` covering POST/GET `/chat`, multi-turn LLM history continuity, 500/404 envelopes, `serialize_content`, `get_stock_info` mocks, `MAX_ITERATIONS` fallback, and store isolation across tests. Centralizes Phase 1–2 checklist coverage with no live OpenAI or Yahoo Finance calls. Adversarial gap deferred: lifespan `RuntimeError` when `OPENAI_API_KEY` is an empty string is not falsified in this slice (would require a separate app import path).
